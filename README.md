# MobilityX Automation Framework

MobilityX is a powerful and flexible automation framework designed for testing enterprise-grade applications. Built with scalability in mind, it can be used for everything from rapid validation of small modules to full-scale end-to-end testing of complex enterprise systems.

## 🚀 Features

- Supports modular and reusable test components
- Scalable from microservices to large enterprise apps
- Easy configuration and environment management
- Cross-platform test execution
- Built-in reporting and logging
- Seamless CI/CD integration

## 📦 Tech Stack

- Java
- Selenium and Appium
- TestNG 
- Maven 
- GitHub Actions

## ✅ Prerequisites

Before running the framework, make sure the following tools are installed and configured on your system:

### 🔧 Common Requirements (All Platforms)

- **Java Development Kit (JDK 11 or higher)**
- **Appium Server** (for mobile test automation)
- **Android Studio** (for ADB and emulator support)
- **Node.js & npm** (required by Appium)
- **Maven**(for dependency management)
- **Google Chrome** (if testing web apps)
